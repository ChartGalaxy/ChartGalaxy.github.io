数据来源与使用说明

规模与任务说明来自各数据集官方数据卡。下载量使用 Hugging Face API 的 downloadsAllTime（历史累计）字段，仅统计本页的 5 个仓库。刷新失败时保留带日期的完整快照；仓库下载量不是独立用户数，资源规模也不是去重后的图像总数。

ChartGalaxy++ 的 18,897,483 个场景图节点与 39,989,150 条关系记录对应 217,195 张信息图表；InfoDet 的 14,227,680 个边界框标注对应 101,264 张信息图表。ChartGalaxy++ 与 DAD 的图表集合均与 ChartGalaxy 存在来源关联，二者及基础数据不直接相加。

请以各仓库授权为准。ChartGalaxy 元数据标注 CC BY-NC 4.0、正文提及 Apache 2.0，使用前请确认数据与代码的适用范围；ChartGalaxy++ 贡献的场景图标注采用 CC BY-NC 4.0（第三方图表内容保留原权利）；InfoDet 标注 CC BY-NC 4.0，InfoChartQA 标注 CC BY 4.0，DAD 采用分来源许可说明（见其仓库 LICENSE.md）。
